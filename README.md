# Listing_Board

Google Apps Script 기반 리스팅 운영 및 분석 코드입니다.

- `apps-script/`: 운영 스프레드시트용 코드. B008 / P012 기준.
- `analytics-script/`: 별도 분석 스프레드시트용 코드. A004 기준.

두 폴더는 서로 다른 Apps Script 프로젝트입니다. 각 프로젝트에 해당 폴더만 적용합니다. Google 스프레드시트 데이터, 인증 파일 및 실제 프로젝트 연결 정보는 포함하지 않습니다.

## 브랜치

- `기준본`: 검증된 복구 기준. 적용이 확인된 버전으로만 갱신합니다.
- `운영본`: 실제 적용한 코드 기록. 운영 적용 확인 후 갱신합니다.
- `교체본`: 다음에 적용할 변경을 준비하고 검토하는 브랜치입니다.

초기 세 브랜치는 같은 코드로 시작합니다. 운영 코드는 사용자 적용 보고로 재구성한 B008/P012이며 원격 프로젝트를 직접 조회하지 않았습니다. 분석 A004는 로컬 최신 배포본이며 실제 적용 여부는 확인되지 않았습니다. 따라서 초기 `운영본`도 원격 코드와의 일치를 보증하지 않습니다.

## 적용

운영 프로젝트에는 `apps-script/` 안의 동일 이름 파일을 적용합니다. 기존 운영 환경을 초기화하지 말고 변경 파일과 적용 안내를 확인합니다.

분석 프로젝트 설치와 A004 설정은 `analytics-script/README.txt`를 따릅니다. 분석은 운영 스프레드시트를 조회하는 별도 프로젝트입니다.

clasp 사용 시 `.clasp.example.json`을 참고해 로컬 `.clasp.json`을 만들고, 대상 프로젝트에 맞춰 `scriptId`와 `rootDir`을 설정합니다. 연결 파일과 인증 정보는 커밋하지 않습니다. 브랜치 전환이나 GitHub 업로드만으로 Apps Script에 자동 배포되지는 않습니다.
