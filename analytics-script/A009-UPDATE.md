# A009 일반 분석 개편

분석 Apps Script에서 Code.gs와 Layout.gs를 전체 교체한 뒤 refreshListingAnalytics를 실행합니다. CONFIG의 근무비율과 외부 지원 목록은 유지합니다. 작업자 월별은 작업자 순위로 변경되며 순위는 정수로 표시됩니다. 투입 계획 설정은 더 이상 읽거나 생성하지 않으므로 삭제해도 됩니다. 운영 코드와 별도 실행 11월 보고는 변경하지 않습니다.

## 비교 지표

- 2P와 3P의 VI·기록일·생산성을 분리하고 단계 합계는 표시하지 않습니다. 각 단계의 d는 그 단계의 작업자별 고유 기록일×CONFIG 근무비율입니다. 같은 날 여러 세션은 해당 단계 내에서 한 번만 셉니다. 순위 최소 기록일도 해당 단계의 날짜 수를 사용합니다.
- 월별·주별 증감률을 3P와 2P 각각 표시합니다. 주별 블록 및 블록 안 주차 모두 최신순입니다.
- 월별 전체 효율 = 내부 3P 리스팅 VI ÷ (내부 크롤링 d + 내부 리스팅 d). 크롤링·리스팅 공정 d를 요청대로 더합니다. 같은 사람이 두 공정을 수행한 날은 양 공정에 잡힐 수 있어 실제 전일 노동량을 직접 측정한 값은 아닙니다. 2P는 이 지표에 포함하지 않습니다.

## 크롤링 효과

C는 현재 CRAWL_COMPLETED, 그 외는 N입니다. 상태를 대문자·공백 정규화하며 요청이 없는 세션도 N에 포함합니다. C VI·C d와 N VI·N d는 해당 타겟의 리스팅 실적·리스팅 투입일입니다. 크롤링 d는 크롤링 작업 자체에만 사용합니다. 현재 상태를 과거 실적에 소급합니다.

CRAWL 세션은 Started At(없으면 Ended At) 날짜를 사용하며 작업자·날짜별 중복을 제거합니다. 완료 크롤링 요청의 현재 Total VI는 해당 요청·작업자의 마지막 세션 월에 한 번 귀속합니다. 작업자가 바뀐 경우 연결된 실제 세션 작업자를 우선합니다. 세션이 없는 완료 건은 REQUESTS Started At의 월에 요청당 1d×현재 크롤링 작업자 근무비율을 추가합니다. 여러 요청의 추정 d는 각각 더하며 실측·추정 구분 없이 합산 표시합니다. 세션과 요청 Started At 모두 없는 건은 날짜를 만들지 않고 월별 귀속에서 제외해 실행 로그에 남깁니다.

해석 표·확인 불가 VI·일별/7일 배수·누락 점검 표는 제거했습니다. 월별 C/N 생산성, 크롤링 작업량·투입, 같은 작업자/Node 비교만 표시합니다.

## 리드타임

전체 리드타임과 홀드 제외 리드타임을 하나의 표로 합쳤습니다. 전체 리드타임은 유효한 완료 요청 전체, 홀드 제외 값은 Blocked Time (Hours)가 숫자이며 0 이상이고 전체 경과시간 이하인 요청만 사용합니다. 누락 홀드를 0으로 만들지 않습니다. 확인 필요 열 대신 홀드 제외 표본 수만 표시합니다. 두 값은 달력일이며 생산성 d와 다릅니다. Node별 표도 같은 방식입니다.

## 투입 계획

맨 위에 현재 남은 요청 수·VI·필요 크롤링 d·리스팅 d·총 d를 표시합니다. DONE/DROP/취소 상태 및 2P Lite 전환 요청, 이미 3P 완료 VI가 Total VI에 도달한 요청은 제외합니다. 홀드는 전체 잔량에 포함하되 재개 가정의 추가 d로 분리합니다. 신규 유입·대기·휴일·분할 제약은 예측하지 않습니다.

- 남은 VI = 현재 Total VI - 현재 3P Completed VI. 총량이 미확정이면 전체 REQUESTS의 유효한 비음수 Total VI 평균으로 추정합니다. 완료 VI가 미기록이면 0으로 취급합니다. 평균 자체도 없으면 계산값을 공란으로 둡니다.
- 현재 크롤링 완료 잔량은 C 리스팅만, 크롤링 대기 잔량은 크롤링+ C 리스팅, 그 외는 N 리스팅으로 계산합니다. 크롤링 대기는 전체 타겟 VI를 크롤링한다고 가정하고 리스팅은 잔여 VI만 사용합니다.
- 현재 예측은 각 공정의 가장 최근 양수 VI/d를 쓰며 기준 월을 따로 표시합니다. 필요 공정의 표본이 없으면 해당 총 d를 공란으로 둡니다. 월별 잔량 예측은 그 월의 생산성만 사용합니다.
- 요청 규모 비교는 전체 REQUESTS의 공통 평균 VI를 모든 월에 동일하게 놓습니다. 비크롤링 1/5개, 크롤링 1/5/10개 필요 d를 표시합니다. 크롤링 방식에는 크롤링 d와 C 리스팅 d가 모두 포함됩니다.
