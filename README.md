# Listing_Board

Google Apps Script 기반 리스팅 운영 및 분석 코드입니다.

- `apps-script/`: 운영 스프레드시트용 코드. B008 / P012 기준.
- `analytics-script/`: 별도 분석 스프레드시트용 코드. A006 개발본: 환산 근무일 생산성·월별 크롤링·투입 계획·홀드 보정.

두 폴더는 서로 다른 Apps Script 프로젝트입니다. 각 프로젝트에 해당 폴더만 적용합니다. Google 스프레드시트 데이터, 인증 파일 및 실제 프로젝트 연결 정보는 포함하지 않습니다.

## 브랜치

- `교체본`: 새 기능과 수정 사항을 개발하고 검토하는 브랜치입니다.
- `기준본`: 검증을 마친 교체본을 반영하는 기본 브랜치입니다. 회사 운영·분석 파일에는 이 브랜치의 해당 폴더를 적용합니다.

개발 → 교체본에서 검증 → 기준본에 병합 → 회사 운영·분석 파일에 적용하는 순서로 관리합니다. 별도의 운영본 브랜치는 사용하지 않습니다.

초기 코드는 운영 B008/P012 및 분석 A004입니다. 운영 코드는 사용자 적용 보고로 재구성했으며 원격 프로젝트를 직접 조회하지 않았습니다. 분석 A004의 실제 적용 여부는 확인되지 않았습니다. 기준본에 병합하거나 GitHub에 푸시해도 회사 Apps Script에 자동 반영되지 않으며, 각 프로젝트에 별도로 적용해야 합니다.

## 적용

운영 프로젝트에는 `apps-script/` 안의 동일 이름 파일을 적용합니다. 기존 운영 환경을 초기화하지 말고 변경 파일과 적용 안내를 확인합니다.

A006 기존 분석 파일 업데이트는 `analytics-script/A006-UPDATE.md`, 신규 설치 및 기존 설정은 `analytics-script/README.txt`를 따릅니다. 분석은 운영 스프레드시트를 조회하는 별도 프로젝트입니다.

clasp 사용 시 `.clasp.example.json`을 참고해 로컬 `.clasp.json`을 만들고, 대상 프로젝트에 맞춰 `scriptId`와 `rootDir`을 설정합니다. 연결 파일과 인증 정보는 커밋하지 않습니다. 브랜치 전환이나 GitHub 업로드만으로 Apps Script에 자동 배포되지는 않습니다.
