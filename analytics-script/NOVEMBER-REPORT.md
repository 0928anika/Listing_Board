# 11월 보고 — 주차별 비교·전체 C/N·통합 VI/d

기존 분석 Apps Script의 LeadershipReport.gs만 전체 교체하고 **buildNovemberReport**를 실행합니다. 일반 refreshListingAnalytics 및 운영 코드는 변경하지 않습니다. 이전 실행 함수도 같은 함수를 호출합니다.

## 1. 월별 통합 생산성

- 리스팅 VI/d: 리스팅 완료 VI / 리스팅 d
- **크롤링+리스팅 통합 VI/d: 리스팅 완료 VI / 크롤링+리스팅 총 d**

크롤링 세션이 없으면 Started At 월에 요청당 1일×크롤링 작업자의 CONFIG 근무비율을 더합니다. 0.5 근무자는 0.5d입니다. 관측 세션은 사람·날짜를 중복 제거하고, 요청별 가정 d는 추가합니다. 화면에는 합산 총 d만 표시하며 실제 작업시간이 아닌 계획 기준입니다.

## 2. N VI/d · C VI/d · 배수

- N VI/d: 해당 작업자·해당 월의 비크롤링 완료 VI / 비크롤링 기록일의 보정 d
- C VI/d: 해당 작업자·해당 월의 크롤링 완료 VI / 크롤링 기록일의 보정 d
- 배수: C VI/d / N VI/d

**양쪽 유형이 각각 2개 이상의 고유 기록 날짜를 가져야 비교에 포함합니다.** 보정 후 2d가 아니라 기록 날짜 2일입니다. 0.5 근무자도 각 유형 2기록일이면 포함됩니다. 같은 날 두 방식이 섞인 작업일은 비교에서 제외합니다.

한쪽 날짜가 1일뿐인 고배수도 제외합니다. 특정 이름을 제외하는 규칙은 없습니다. 조건을 통과한 비교 사례를 1배 이하도 포함해 배수 순으로 최대 5명 표시하고, 부족해도 전월비·참고 사례로 채우지 않습니다.

표 아래에는 전체 C VI/d, 전체 N VI/d 두 값만 표시합니다. TOP 5가 아닌 같은 2일 기준을 통과한 전체 비교 대상자의 C VI 합계/C d 합계, N VI 합계/N d 합계입니다. 개선 배수가 1 이하인 비교 대상자도 전체 합계에는 포함됩니다. 개인별 평균이나 중앙값은 아닙니다.

## 3. 현재 시트 전체 평균 VI를 고정한 방법별 d

현재 REQUESTS에 있는 고유 요청 중 숫자 Total VI가 0 이상인 값을 모두 평균 냅니다. 숫자 0은 포함하고 빈칸·문자·오류·음수는 제외합니다. 작업한 월, 요청 상태, 크롤링 여부로 평균 크기를 바꾸지 않습니다. 이 공통 평균 V를 9·10·11월 모두 동일하게 적용하고 전체 표본 수를 표시합니다.

월별 속도를 이용해 다음 5개를 비교합니다.

- 크롤링 없이 요청 1개: V / 전체 N VI/d
- 크롤링 없이 요청 5개: 위 값 × 5
- 크롤링해서 요청 1개: **V / 크롤링 VI/d + V / 전체 C VI/d**
- 크롤링해서 요청 5개: 위 합계 × 5
- 크롤링해서 요청 10개: 위 합계 × 10

크롤링 방식은 크롤링 단계와 리스팅 단계에 필요한 d를 모두 포함합니다. 전체 C/N 속도는 2번과 같은 2일 기준 통과 비교 대상자의 합계 속도입니다. 크롤링 VI/d에는 기존의 세션 누락 시 요청당 1일×근무비율 가정이 포함됩니다.

3번은 모든 요청을 비크롤링으로 리스팅하는 경우와 모두 크롤링 후 리스팅하는 경우의 표준 물량 계획 비교입니다. 1번 통합 VI/d는 실제 월의 크롤링·비크롤링 혼합 실적이므로 3번의 순수 방식 가정과 다릅니다. 실제 요청별 경과일 평균이나 납기 보장은 아닙니다. 속도 기록이 없으면 임의의 다른 속도를 넣지 않고 비교 기록 없음으로 표시합니다.

## 4. 월요일~일요일 주차별

- W1: 11/2~11/8
- W2: 11/9~11/15
- W3: 11/16~11/22 (기준일 이후는 포함하지 않음)
- 이후 같은 방식. 11/1 기록이 있으면 전월 연결주로 따로 표시

각 주의 리스팅 작업 요청 수, 그중 크롤링 요청 수·비중, 주간 처리 VI, d, VI/d를 표시합니다. 이는 해당 월/주에 완료된 요청 수가 아닙니다. 미완료 요청이나 다음 달에 완료되는 요청도 해당 주에 3P 작업 기록이 있으면 포함합니다. 같은 요청이 여러 날짜·여러 작업자에게 있어도 주 안에서는 한 번만 세며, 다른 주에 다시 작업하면 그 주에도 포함합니다.

요청 비중은 해당 주 3P 작업기록이 있는 고유 요청 중 현재 CRAWL_COMPLETED인 요청 건수 비중입니다. 주간 처리 VI는 해당 주 세션의 순증 VI 합계이며 요청 전체 VI나 요청 DONE 수가 아닙니다. 월별 VI 비중과 분모가 다릅니다. 주간 VI/d는 주간 VI 합계/주간 d 합계로 계산하며 일별 VI/d의 평균이 아닙니다. 일별 표와 7일 이동 VI/d는 제거했습니다.

9월 유효 기간·기준일·현재 요청 속성 사용·자료 누락 범위는 기존 정책을 유지합니다. 원본과 트리거를 변경하지 않으며 11월 보고는 별도 실행할 때만 갱신됩니다. 업무 난이도·배정 차이가 남으므로 관측 비교와 계획값을 허브의 인과적 효과로 확정하지 않습니다.
