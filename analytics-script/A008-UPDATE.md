# A008 기존 분석시트 VI/d 전환

분석 프로젝트의 Code.gs와 Layout.gs를 교체한 뒤 refreshListingAnalytics를 실행합니다. 운영 프로젝트 코드는 교체하지 않습니다. CONFIG G:H 근무비율과 외부 지원 목록은 유지합니다. 새 작업시간 탭은 실행 시 생성됩니다. LeadershipReport.gs와 별도 실행 11월 보고는 변경하지 않습니다.

- 월별·주별·작업자 순위·일별·외부 지원·내외부·Node·크롤링 효과 비교는 VI/d를 사용합니다. 기록된 시간의 길이와 무관합니다.
- d = 작업자별 고유 세션 기록일 × CONFIG 근무비율의 합계. 0.5 근무자 2기록일 = 1d. 비율 미지정은 1. 출근일이나 실제 전일 투입을 직접 측정한 값은 아닙니다.
- 일반 2P·3P 표는 같은 사람·날짜를 한 번 센 공통 d를 사용합니다. 단계 VI 합계는 2P+3P 단계 처리량이며 고유 상품 수가 아닙니다. 전체 생산성은 전체 VI ÷ 전체 d로 재계산합니다.
- 크롤링 효과 표는 내부 3P만 대상으로 유형별 d를 사용합니다. C/N을 같은 날 수행하면 각각의 유형 분모에 포함되므로 두 유형의 d를 더하지 않습니다. 현재 CRAWL_COMPLETED 상태로 소급 분류하며 인과 효과를 확정하지 않습니다.
- ACTIVE 제외, 종료일 기준, 장기 집계는 COMMITTED만 포함합니다. 0시간 또는 시간 오류도 VI/d에는 포함합니다. VI 누락은 분자에서 제외하고 확인된 기록일은 포함해 과대평가를 줄입니다. 음수 정정은 유지합니다.
- 순위는 시간 하한을 폐기합니다. 선택 설정 MIN_RANK_DAYS는 보정 전 최소 기록일이며 기본 1입니다. 기존 MIN_RANK_HOURS는 더 이상 비교·순위에 사용하지 않습니다. 기간 내 해당 단계 기록이 있는 작업자만 단계 순위에 포함합니다. 동률은 공동순위입니다.
- 작업시간 탭에서 개인별 월/일 기록 h와 크롤링·3P·2P 시간, 시간 미기록 행 수를 확인합니다. h는 비교·순위에 쓰지 않으며 실제 투입시간으로 보정하거나 추정하지 않습니다. 장기 집계에 없는 CRAWL 이력은 복원할 수 없습니다.
- 리드타임과 홀드 제외 처리기간은 달력일로 표시합니다. 근무일 d와 다릅니다. 기존 투입 계획은 VI/d를 유지합니다.
