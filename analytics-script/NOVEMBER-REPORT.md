## 3번: 요청 수를 필요 d로 바꾸기

- 평균 요청 VI: 해당 월 실제 3P 작업 기록이 있는 고유 요청 중 현재 Total VI가 유효한 요청의 평균입니다. 표본 수/작업 요청 수를 표시합니다. 한 요청이 여러 세션이나 작업자에게 나타나도 한 번만 셉니다.
- 리스팅 요청 1개 d = 평균 요청 VI / 월 리스팅 VI/d.
- 준비+리스팅 요청 1개 d = 평균 요청 VI / 월 준비+리스팅 모형 VI/d. 요청 5개·10개는 이 값의 5배·10배입니다.
- 요청 크기 차이를 제외한 비교를 위해 11월 평균 VI와 같은 크기의 요청 1개를 각 월 속도로 처리할 d도 표시합니다.
- 실제 요청별 소요기간의 산술평균이 아니라, 현재 요청 크기와 월별 관측+추정 투입 생산성으로 만든 계획값입니다. 인원·대기·병목·신규 유입에 따른 기간 예측은 별도입니다.

## 누락된 크롤링 d 추정

완료 요청에 유효한 CRAWL 세션이 없으면 요청 Started At 월로 물량을 귀속하고 **요청당 1일 × 현재 크롤링 작업자의 CONFIG 근무비율**을 추가합니다. 0.5 근무자는 요청당 0.5d입니다. 같은 날짜에 여러 요청이 있어도 이 추정분은 요청별로 각각 추가합니다.

관측된 세션의 d는 사람·날짜를 중복 제거합니다. 총 모형 d는 크롤링+리스팅 관측 합집합 d에 요청별 추정 d를 더한 값입니다. 따라서 실제 노동시간이나 실제 출근일 합계가 아니라, 사용자가 지정한 1일 가정의 계획 기준입니다. 다른 크롤링 작업자의 세션이라도 해당 요청에 유효 기록이 있으면 다시 1일을 추정하지 않습니다. 작업자/Started At이 없으면 추정할 근거가 없어 확인 필요로 남깁니다.

## TOP 5와 바로 아래 전체 통계

월별 사례는 다음 순서로 실제 작업자를 채웁니다.

1. 크롤링/비크롤링 VI/d가 모두 양수이며 배수가 1보다 큰 사례. 각 방식 한 기록일만 있어도 포함하되 2일 미만은 소표본으로 표시합니다.
2. 부족하면 같은 작업자의 전월 대비 VI/d 개선 사례를 전월비로 표시합니다.
3. 그래도 부족하면 해당 월 VI/d가 높은 실제 작업자를 월 생산성 참고로 표시합니다. 비교할 기준이 없으므로 배수를 만들지 않습니다.

월 작업자가 5명 미만이면 없는 사람을 만들어 채우지 않고 인원 수를 표시합니다. C/N은 같은 날 혼합 작업일을 제외하므로 비교 인원이 줄 수 있습니다. 한 방식만 수행한 인원, 혼합일 때문에 비교에서 빠진 인원, 소표본 인원을 표시합니다.

TOP 5 바로 아래에 **전체 작업자의 VI/d 중앙값·평균·인원 수**, **전체 비교 가능자의 C/N 배수 중앙값·평균·인원 수**를 나란히 표시합니다. C/N 전체 통계에는 개선 배수가 1 이하인 사람도 포함하며 TOP 5만 평균 내지 않습니다. 팀 VI/d(전체 VI/전체 d)와 개인 VI/d의 산술평균은 다릅니다.

## 11월 일별 심층
